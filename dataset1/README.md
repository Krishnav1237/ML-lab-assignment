# Dataset 1 - Skin Disease Classifier

This folder contains the training pipeline for Dataset 1.

## Files

- `kaggle_skin_disease_classifier.py` - Complete training notebook
- `config_kaggle.py` - Configuration file

## Setup Instructions

1. Upload your dataset to Kaggle Datasets
2. Update `DATASET_NAME` in `config_kaggle.py`
3. Create a Kaggle notebook
4. Copy-paste `kaggle_skin_disease_classifier.py` content
5. Enable GPU and run

## Dataset Structure Expected

```
your-dataset-name/
├── Class1/
├── Class2/
├── Class3/
├── Class4/
├── Class5/
└── Class6/
```

Update the `CLASSES` variable in the notebook to match your dataset.
